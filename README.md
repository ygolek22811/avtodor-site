# Официальный сайт детского спортивного клуба «Автодор» (Смоленск)

Современный презентационный сайт детского спортивного клуба «Автодор» (ДСК «Автодор»). Разработан в стилистике **Elite European Football Editorial** с глубокой тёмной палитрой, акцентным оранжевым цветом (`#FF5A1F`) и выразительной спортивной типографикой.

---

## 📁 Где редактировать данные клуба (для не-программистов)

Все тексты, возрастные группы, контакты, тренеры и фотографии вынесены в **один удобный файл**:
👉 **`src/config/clubData.ts`**

Вам не нужно разбираться в коде компонентов — достаточно открыть этот файл в любом текстовом редакторе (VS Code, Блокнот и т.д.) и изменить нужные строчки.

### 1. Как изменить контакты (телефон, мессенджеры, соцсети)
В файле `src/config/clubData.ts` найдите блок `CLUB_CONTACTS`:
```typescript
export const CLUB_CONTACTS = {
  city: "Смоленск, Россия",
  addressNote: "Информация о месте проведения тренировок уточняется по запросу",
  
  // Введите ваш телефон:
  phoneDisplay: "8-910-787-34-44",     // Отображается в тексте
  phoneRaw: "+79107873444",            // Для автоматического звонка по клику
  
  // Введите ссылки:
  telegramUrl: "https://t.me/dskavtodorsmol",
  instagramUrl: "https://www.instagram.com/dck_avtodor?dlrf=dzRzY3ZkNTM0YjI3",
  vkUrl: "https://vk.ru/dfcavtodor",
  email: "",
};
```
> **Важно**: если оставить значение пустым `""`, кнопка не будет ломаться или вести на ошибку 404 — интерфейс покажет статус «Слот подготовлен».

- ЦСКА (Москва)

- «Краснодар» (Краснодар)
- «Спартак» (Москва)
- «Ротор-Москва» (Москва, футбольная школа)

Если в дальнейшем клуб получит официальные файлы логотипов, достаточно положить их в папку `public/logos/` и прописать свойство `badgeUrl: "/logos/cska.png"` в соответствующем объекте клуба. Секция автоматически отобразит логотип.

### 3. Как добавить или изменить тренеров
В блоке `COACHES_STATUS` и `COACHES_LIST` в файле `src/config/clubData.ts`:
1. Установите `isProfilesPublished: true`.
2. Заполните массив `COACHES_LIST`:
```typescript
export const COACHES_LIST = [
  {
    id: "coach-1",
    name: "Иван Иванов",
    role: "Старший тренер",
    experience: "Опыт работы: 7 лет",
    license: "Лицензия UEFA / РФС",
    bio: "Воспитанник смоленского футбола. Специализация на раннем развитии детей.",
    photoUrl: "https://... или путь к фото"
  }
];
```

В блоке `CLUB_INFO` и `CLUB_GALLERY` в `src/config/clubData.ts` подключены фотографии:
- **Главный экран (Hero)**: `main.png` (путь `/images/main.png`)

- **Командный разбор игровых ситуаций**: `razbor.png` (путь `/images/razbor.png`)

---

### 5. Как редактировать блок вопросов и ответов (FAQ)
В блоке `FAQ_DATA` в `src/config/clubData.ts` можно изменять, добавлять или удалять вопросы для родителей:
```typescript
export const FAQ_DATA = [
  {
    id: "faq-custom",
    question: "Ваш вопрос...",
    answer: "Подробный ответ клуба..."
  }
];
```
Каждый вопрос автоматически оформляется с аккуратным знаком «+», который плавно поворачивается при раскрытии ответа.

## 🚀 Как опубликовать сайт на Cloudflare Pages

Сайт представляет собой лёгкий статический одностраничник на Vite + React + TypeScript, идеально подходящий для бесплатного хостинга Cloudflare Pages.

### Шаг 1. Локальная сборка (проверка)
В терминале проекта выполните:
```bash
npm run build
```
После завершения в корне проекта появится папка `dist` — это готовая оптимизированная статическая версия сайта.

### Шаг 2. Публикация через GitHub в Cloudflare Pages
1. Загрузите проект в ваш репозиторий на GitHub.
2. Откройте панель [Cloudflare Dashboard](https://dash.cloudflare.com/) → **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**.
3. Выберите ваш репозиторий с ДСК «Автодор».
4. В настройках сборки (*Build settings*) укажите:
   - **Framework preset**: `Vite`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
5. Нажмите **Save and Deploy**. Через 1 минуту ваш сайт будет опубликован по всему миру на собственном домене Cloudflare или вашем личном домене (например, `avtodor-smolensk.ru`).

## 🎨 Фирменный стиль
- Основной фон: глубокий чёрный `#0A0B0D` и графитовый `#151719`
- Фирменный акцент: энергичный оранжевый `#FF5A1F`
- Текст: контрастный белый `#FFFFFF` и нейтральный `#E6E8EB`
- Шрифты: `Oswald` (атлетический узкий спортивный шрифт) и `Manrope` (современный чистый sans-serif с превосходной кириллицей).
